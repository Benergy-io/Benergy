Common Questions

How do you collect GPU metrics? +

Our lightweight agent (5MB) runs on your GPU node and reports metrics via HTTPS every 60 seconds. No code access, no dependencies, full data privacy.

Is my GPU data encrypted? +

Yes. All data is encrypted in transit (HTTPS) and at rest (AES-256). You can self-host the agent if you prefer.

How is Benergy different from custom Prometheus setups? +

Prometheus requires hours to set up and maintain. Benergy is 5 minutes, built specifically for GPU optimization, and includes actionable recommendations.

Do you support custom integrations? +

Yes. Enterprise customers can integrate with Slack, PagerDuty, DataDog, custom webhooks, and more. API access coming in August.

Can I host Benergy on-premise? +

Self-hosting is available for Enterprise customers. Contact sales@benergy.io for details.
